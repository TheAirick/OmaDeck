# OmaDeck v0.10.0 — Watch on the deck

## What's new

- **Optional YouTube Watch mode:** transfer a supported video from Firefox, Zen
  or Chromium to OmaDeck near its current timestamp, including from a background
  tab. Return resumes the original document at the latest playback position.
- **Native-feeling presentation:** a left-anchored video with compact touch
  controls, seek, captions, a themed border and focused/fullscreen mode.
  Volume/System resize the video as drawers open; other overlays retain playback.
- **Reliable exits:** Close works independently of Return. Closing the original
  browser tab changes Return to Close without touching another browser video.
- **Clear load failures:** unsupported embedded videos stay in the browser with
  an explanation. A failed destination load does not rewind browser playback.
- **Monitor inputs:** resolve the saved display from its connected hardware
  identity without a full DDC scan for every input tap.
- **Touch and System reliability:** cancel interrupted device contacts, ignore
  stale buffered input after reconnect, preserve application/clipboard rows
  during refresh, validate Force Kill targets, and detect stale native builds.

## Install or update

The standard dashboard still needs no build:

```bash
omarchy plugin update pretty.omadeck
omarchy restart shell
```

If using native touch/tray integration, rebuild with the installed plugin's
`scripts/build-native` before restarting. Keep the documented host input guard.

**Watch mode is an optional preview**, requiring a separate native player build
and companion extension. See the [Watch setup guide](../WATCH_MODE.md).
Firefox/Zen currently uses an unsigned temporary add-on, reloaded after a browser
restart. Chromium uses an unpacked extension. This release does not publish an
extension to Mozilla Add-ons or the Chrome Web Store.

YouTube videos that disallow embedding cannot play in this player. Its temporary
profile does not reuse browser cookies. Handoff starts another player, so a short
loading delay is expected. Other video websites and DRM playback are not supported.

## Verification and packaging

The source package is generated from the exact committed Git snapshot; browser
ZIPs contain the corresponding extension code. `release.json` records the full
commit and `SHA256SUMS` covers the source and companion packages. Native binaries
are built locally against the installed Qt libraries, not distributed in these
archives. The local suite passes **253 tests, zero failures or skips**, including the
optional Watch host build and isolated WebEngine load probe. The release body
records hosted CI evidence for the exact pushed commit.

Real Zen/Chromium tests exercised timestamp handoff, background tabs, Return and
renderer/browser loss. An ended-video/source-tab-close reproduction passed in
Zen without changing playback in a new browser document. Live Edge geometry and
native touch checks passed. Physical suspend/USB/lock recovery and a clean-machine
Watch installation were not repeated for this release. Monitor lag improvement
is measured as reduced DDC work, not a confirmed elimination of all playback hitches.

Application code remains MIT licensed. The bundled Ocean sound is unchanged and
retains its [CC-BY-SA-4.0 attribution](../../assets/sounds/README.md).

Marketplace snapshot verification and standard-install availability are separate
from repository publication. The optional browser setup remains manual.
