# OmaDeck v0.8.0 — Preferences, installation, and reliability

This release includes the complete changes since v0.7.2. Erik accepted the
release candidate's manual tests on the Corsair Xeneon Edge on September 7,
2026, including touch, lock/unlock, reconnect, suspend/resume, and fresh-login
behavior. Other hardware has not been certified by those results.

## Preferences and controls

- Unified Preferences for OmaDeck settings and Omarchy settings handoffs.
- Persistent display and optional native touchscreen selection, with visible
  save failures and retry.
- Precise timer duration fields, compact controls, sound selection, and clock
  progress while Weather remains accessible. Completion opens Dismiss.
- Refined Clock, Weather, and drawer/overlay presentation at constrained sizes.

## Installation

- Standard installation requires no native build and uses compositor-managed
  touch: `omarchy plugin add https://github.com/TheAirick/OmaDeck.git --enable`.
- The direct touch bridge and tray controller remain optional. Build them with
  `~/.config/omarchy/plugins/pretty.omadeck/scripts/build-native`, then run
  `omarchy restart shell`. Rebuild them after updating if using native mode.
- Marketplace snapshot approval and the Copy install button are separate
  maintainer-controlled steps; publication of this release does not imply either.

## Reliability

- Media actions target the displayed MPRIS player and respect its capabilities.
  Seeking reconciles with the actual player after track changes or rejected seeks.
- Clipboard actions preserve full content behind bounded previews and reject
  stale entries.
- Settings failures recover on retry, including reselecting an existing timer
  sound. Existing settings retain their JSON formats.
- Lock state blocks interaction; cancelled contacts cannot replay after unlock.
- Closed drawers pause monitoring. System failures retain the last good snapshot
  with age and retry feedback. Helpers have output limits and deadlines.

## Validation and recovery

The release checks cover settings upgrade/rollback, real offscreen Quickshell
fixtures, private D-Bus media lifecycle tests, bounded helper recovery, and a
clean native build with three CTests. Exact results and remaining scope are
recorded in `docs/RELEASE_CHECKLIST.md` and the release PR's CI checks.

Rollback restores the prior source and saved settings. Native users must also
rebuild the matching source before reloading the shell. MPRIS support depends on
the media application; EQ/DSP and universal audio metadata are outside this release.
