# OmaDeck v0.9.0 — Make the deck your own

This release brings the dashboard, workspaces, monitor controls, notifications,
and launcher improvements developed since v0.8.1 into the public release.

## What changed

- **Apps and commands:** add any installed desktop app, including entries hidden
  from Omarchy’s menu, or create a named button for a script or shell command.
  Choose its icon, working folder, and optional terminal. Search, edit, reorder,
  and remove buttons in Preferences with a touch or physical keyboard. Saving
  a command never runs it; tapping its Command Center button does.
- **Launcher scrolling and layout:** apps use a responsive grid across the
  available width, with selection actions below. App/icon refreshes preserve
  scroll position, swipes have bounded momentum, and dragging does not activate
  buttons underneath.
- **Notifications:** a themed recent-history list, full-message reader, and
  compact quick controls replace the old drawer. Clear requires confirmation;
  missing services and action failures have visible feedback.
- **Workspaces:** Command Center’s Overview is now Workspaces, showing numbered
  workspaces 1–5 and their open apps. Tap the scratchpad to show or hide it;
  return and park actions stay available. Active outlines remain visible when
  the pointer enters OmaDeck. An option controls whether the view closes after
  switching, and overlay touches cannot trigger dashboard controls underneath.
- **Monitor switching:** configure your own displays, connected inputs, labels,
  and icons. A guided setup checks DDC/CI software and display access, opens a
  visible preparation terminal when needed, and explains monitor-side setup.
  Controls are optional; new installs contain no personal monitor/input mapping.
- **Dashboard customization:** enter Customize layout in Preferences to move
  panels, swap or place them at edges, and resize dividers. Done saves; Cancel
  restores the prior layout. Long-pressing the normal dashboard no longer
  rearranges panels or interferes with timer controls.
- **Audio and timer:** choose output speakers/headphones or a microphone from
  Volume. Picker tabs switch immediately without leaving a stale selection.
  Timer duration controls repeat and accelerate while held. KDE Ocean’s timer
  sound is the default, with named choices and previews in Preferences.
- **Touch and themes:** touch releases clear stale hover/tooltip states. Secondary
  text has a theme-aware 4.5:1 contrast floor, improving dates, captions, and
  other muted labels while preserving the active theme.

## Updating

Standard mode needs no build:

```bash
omarchy plugin update pretty.omadeck
omarchy restart shell
```

For optional native touch/tray integration, rebuild before restarting:

```bash
omarchy plugin update pretty.omadeck
~/.config/omarchy/plugins/pretty.omadeck/scripts/build-native
omarchy restart shell
```

The restart briefly reloads the desktop shell and activates the keep-loaded
plugin’s new QML. Native users should retain the documented host input guard
and compositor fallback mapping. See [Configuration](../CONFIGURATION.md).

Existing layout and launcher settings migrate to `dashboard-layout.json` and
`launcher-v2.json`; the old `layout.json` and `launcher.json` remain untouched.
Rolling back retains the earlier release’s layout and buttons; it does not
backport new custom commands or subsequent edits. Other settings remain
per-user. New monitor controls are configured in Preferences → Monitor switching.

The bundled Ocean sound is unchanged and remains under CC-BY-SA-4.0, with its
[upstream attribution and license](../../assets/sounds/README.md). Application
code remains MIT licensed.

## Verification and current limits

The local suite passes **237 tests, zero failures or skips**, including a private
native Release build and all three CTests. Coverage includes real Quickshell
persistence/migration, launcher command quoting and failure handling, notification
fallbacks, workspace/touch navigation, and rendered wide/compact launcher scroll
and geometry regressions. Hosted CI and the exact published commit are linked
in the GitHub release.

Live checks on Omarchy `4.0.0.r2131.g86a2e58-1`, Quickshell 0.3.1, and Qt 6.11.2
confirmed the updated launcher, a responding shell, and guarded native touch
with a connected touchscreen. These are not fresh lock/suspend/USB-recovery or
clean-session installation tests, nor proof of compatibility with every monitor.
The timer still supports one active countdown. Workspace thumbnails/live
previews and workspaces beyond the displayed 1–5 are not added in this release.
Marketplace snapshot verification and standard-install availability remain
separate from this GitHub release.
